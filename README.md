# Ops Platform (working name)

A client-owned operating system for service businesses: every lead channel into
one timeline, an AI front desk that finishes the conversation, booking, quotes,
invoices, payments, follow-up and connectors. The business runs from a folder of
plain files (ICM) that the owner, or the owner's own AI, can edit; the platform
validates and tests each change before it goes live.

Status: scaffold, plus the spec and the Sprint 0 plan. Nothing built yet.
