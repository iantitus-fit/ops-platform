<objective>
Close the core of G-02-1.2: after Send, the sent draft is listed above the holding reply because it keeps the draft's creation time.

Root cause: every thread orders by `messages.created_at, id` (`Conversation.php:73`) and every label shows `created_at`, but a held draft is the same row that later becomes the sent message (D-54), and the holding reply is created just after it (`RunFrontDesk.php:346`, then `:374`). The messages table has no send time: `OutboundSender::transmit()` computes `$sentAt` (line 261) but writes it only to the activity, the conversation and the contact.

Purpose: the owner and Ian see the conversation in the order the customer received it, and every later reader of message time (02-37's holding reply, reply cap and records; 02-39's prompt) has one send time to use.
Output: `messages.sent_at` (schema migration with the partial index recreated, plus a backfill), `Message::happenedAt()`, send-time ordering on `Conversation::messages()`, both time labels on it, tests, one walk-through log line. 02-37 moves the other readers onto it; 02-38 filters /dev/chat; 02-39 uses it in the prompt; `map/` is re-pointed by 02-41.
