## Accomplishments

- WR-01: `SendFixedReply::holdingAlreadySent()` reads the Answered arm in PHP and counts an answered draft only when its `meta.answered_by` is greater than the latest wait-starter's id. The partial holding line that closes the waiting draft is itself the latest wait-starter, so its close no longer ends the wait. Dana's third text ("Hello?") now gets the added-info line and her thread holds exactly one holding reply. The owner-approved control still gets a new holding reply.
- WR-04: in `answerWhileDraftWaits()`, a null verdict with sentences to send, no check-in and `touches_waiting` exactly true goes to the new `answerTouchingWithWholeThreadDraft()`. It sends the sentences with the partial line (the holding reply, D-30), then asks the agent once more (`coverBoth: true`, `budgetFrom: $run->startedAt`). The second draft gets its own words check with the waiting draft's label guard and is stored under `touches_waiting`, replacing the waiting one with no new alert (D-22). A failed or blank second call stores nothing, so the waiting draft stays live and "The customer wrote again since this draft" still warns the owner.
- The second-call code is no longer copied: `askForWholeThreadReply()` serves both `coverBothDraft()` and the new branch and returns `unusable`, `handed_off` or `checked`.
- WR-07: the hidden-branch tests are split into one test per case, with no ternary inside an assertion and no `return;` inside a test body.

## Decisions Made

- An answered draft with no `answered_by` still ends the wait. `closeAsAnswered()` always writes the id, but HoldingReplyTest closes a draft by hand without one and expects the wait to end. The REVIEW sketch defaulted a missing id to 0, which would have broken that test.
- When the partial line cannot go out (the conversation is paused, or the send failed), the second call is skipped and W stays live. The sentences are not stored in a draft in that case, the same as the existing replace branch.
- WR-04 applies on `touches_waiting` exactly true, as the plan's flagged assumption says.
