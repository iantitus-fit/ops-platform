# Phase 02.1 Plan 11: Live offers and per-reason holding replies Summary

**A discount question now gets every live offer's sentence in the owner's words, sent by code from folder dates read in the business time zone, with the owner's warm discount reply and an alert when nothing is running, and each held reason gets its own holding reply (complaint, discount, general), the complaint line leading any text it shares.**

## Accomplishments

- `OfferSentences::liveToday()` returns `{slug, sentence}` for every offer whose `start_date <= today <= end_date` (no end date means open-ended), where today is `CarbonImmutable::now(<business zone>)->toDateString()`. Edge tests pin 00:05 on the start day and 23:30 on the end day in Chicago (already the next day in UTC) as live, and 23:55 the day before and 00:30 the day after as not live.
- `RunFrontDesk` appends the live offer sentences after any price sentences when `asks_discount` is true, sends them as `code_answer` with no Jev call, and records `meta.offers`. `AgentReply` accepts a blank reply alongside a discount ask and nowhere else.
- A discount ask with no live offer is a code hold, `discount:no_live_offer`, handled like `price:no_sentence`: the owner is alerted, the Needs you reason reads "Held: no offer running today", picked price sentences still go out with the partial holding line, and model words that would have sent are held as the draft. When a price and an offer both cannot be answered the reason is `price:no_sentence`.
- `SendFixedReply::holding(Conversation, ?string $reasonCode)` sends the complaint reply (kind `complaint_holding`) for `COMPLAINT_CODES`, the discount reply (kind `discount_holding`) for `DISCOUNT_CODES`, and the general holding reply otherwise, once per wait. A folder without `discount_reply` sends the holding reply's words.
- A complaint held while sentences ride with it sends one `complaint_holding` text, complaint line first, then the sentences, parts `['complaint_line', 'code_sentences']`, no partial line (D-36). `alertReasonFor()` now reads `SendFixedReply::COMPLAINT_CODES` instead of its own copy.
