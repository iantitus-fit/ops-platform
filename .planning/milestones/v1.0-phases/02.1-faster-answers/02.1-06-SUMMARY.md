# Phase 02.1 Plan 06: Price sentences at sync Summary

**Owner-written price sentences become part of the service file contract, and the sync refuses any whose $ amounts, service name, wording or answer keys do not hold, so code can later send them without Jev.**

## Performance

- **Duration:** 7 min
- **Started:** 2026-10-14T20:19:19Z
- **Completed:** 2026-10-14T20:26:10Z
- **Tasks:** 2 (a tracer and a TDD task)
- **Files modified:** 15

## Accomplishments

- `price_sentences` and `price_default` are valid service front matter and are written into the SPEC service row (field names frozen). The engine column says the sentences are picked and sent by code and checked at sync, and that a model-written price still waits for the owner.
- `Validator::priceSentenceErrors()` checks each sentence, the default included: fill-ins, money words and k shorthand, bare numbers, at least one $ amount, amounts equal to `amounts_cents` (or `price_cents` for an unkeyed sentence) as sets of integer cents, the service name on squished lowercase text, then the promise and never_say checks only. The price and discount-phrase checks are skipped, so "take the $89 off" and "waived" pass.
- File-level checks: `price_policy: none` with any sentence, answers keyed to the file's own intake questions and exact options, one set of questions across keyed sentences, no repeated answer set, keyed sentences need `amounts_cents`, an unkeyed sentence must be alone, and a default needs keyed sentences, a sentence and amounts.
- Example folder: the $89 diagnostic sentence on `ac-repair` and `furnace-repair`, a new `system-replacement.md` (Replacement system) keyed to unit size with a default that opens "That's fine if you're not sure what you have.", `furnace-tune-up` left at `price_policy: none`, a services `README.md` with the plain-words guidance, and the CONTEXT router updated. The voice file is untouched.
- `PriceSentenceValidationTest` holds 22 broken-file rows plus the live-example, case-and-spacing, waived, default-sentence-missing and furnace-tune-up tests. Example file count is 13.
