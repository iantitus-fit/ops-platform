## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing Critical] No second safety line for a burst that already has one**
- **Found during:** Task 1 (wiring the reading into `RunFrontDesk`)
- **Issue:** `answerDanger()` sends a keyword safety line per text and pauses the conversation. Jev's reading of the same burst could then send a second line for the newest text, because the safety origin passes the pause and `SendLifeSafetyLine` only dedupes per text.
- **Fix:** `safetyLineAlreadySent($burst)` (uses `SendLifeSafetyLine::lineSentFor` for each text) gates the reading's safety line.
- **Files modified:** `app/Actions/RunFrontDesk.php`
- **Verification:** `php artisan test --compact tests/Feature/FrontDesk` and the full suite pass; the existing life-safety tests still show one line per text.
- **Committed in:** `8c58670`

**2. [Rule 2 - Missing Critical] Fail-closed accessor for the run's reading**
- **Found during:** Task 3 (passing the reading into six call sites)
- **Issue:** The reading lives in a nullable run-scoped property; a call path that ever reached `decide()` without a reading would have needed a null guard or crashed.
- **Fix:** `reading()` returns a failed, not-run reading when none was made, so such a run holds the model's words as `classifier_failed` instead of sending.
- **Files modified:** `app/Actions/RunFrontDesk.php`
- **Verification:** full suite passes; no test reaches the fallback.
- **Committed in:** `f1b6382`
