### `app/Actions/SendFixedReply.php` (mod) and `app/Actions/SendCodeAnswer.php` (new)

**Analog:** `app/Actions/SendFixedReply.php`

**Fixed-reply send pattern** (lines 38-58, `handoff()` 66-82 is identical minus the guard). ```php

```php
        'kind' => MessageKind::HoldingReply,

        'gate_reason' => 'fixed_reply',
        'gate' => ['version' => 1, 'fixed' => true, 'reason' => ['code' => 'fixed_reply', 'plain' => null]],

} catch (DomainException $exception) {
    report($exception);

    return null;
}
```
Constructor injection to copy (lines 26-30): `FixedReplies`, `ComposeAutomatedText`, `OutboundSender`, all `private readonly`. `SendCodeAnswer` additionally takes the sentences and passes `activity_summary` and `meta` (`price_sentences` with `sentence_key` per service, so the picker can read "last sent" by decoding `meta` in PHP).

```php
->where(fn ($kind) => $kind->whereNull('kind')->orWhere('kind', '!=', MessageKind::HoldingReply))
->where('id', '>', $latest->id);
```

## Shared Patterns

### One outbound door
**Source:** `app/Actions/OutboundSender.php` via `SendFixedReply.php:47`. **Apply to:** `SendCodeAnswer` and every new fixed text. Never add a second send path; pause/STOP/lock/1,600-char guard live there. Compose with `ComposeAutomatedText::forReply` so the disclosure leads the first automated text and the sign-off ends it.

### Code-written text skips Jev, checked at sync
