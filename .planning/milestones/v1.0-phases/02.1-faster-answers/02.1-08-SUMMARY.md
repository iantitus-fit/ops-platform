# Phase 02.1 Plan 08: Price Sentence Sent By Code Summary

**The owner's own price sentence is read from the live version and sent by code (no Jev), alone, with passing model words in one text, or with the partial holding line while the words wait as a draft; every price code cannot answer still reaches the owner, naming the service.**

## Performance

- **Duration:** about 35 min
- **Started:** 2026-10-14 (about 20:10Z; start time not recorded by the executor)
- **Completed:** 2026-10-14T20:45Z
- **Tasks:** 3 (1 tracer, 2 TDD)
- **Files modified:** 10

## Accomplishments

- Tracer: "How much is the diagnostic for my AC?" produces one text, disclosure + `$89` sentence + sign-off, stored as `code_answer` with `gate_reason fixed_reply`, `meta.parts ['code_sentences']`, `meta.price_sentences [{ac-repair, unkeyed, [8900]}]`, no Jev call, no draft, no alert.
- Mixed questions: one combined `agent_reply` text when the words pass all three checks (1,600 characters sends whole, 1,601 turns the words into a `too_long` draft); when the words hold, a `partial_holding` text carries the sentence and the owner's line, the words become the draft, the owner is alerted, and no full holding reply follows (later held drafts in the same wait also get none).
- Holds: `price_policy: none`, unknown slug, keyed service (this plan) and a passing reply riding with an unanswerable price all hold as `price:no_sentence` with `Held: no price on file for <Service name>` (slugs not in the folder read `a service not in your folder`), an empty draft body when the model wrote nothing, and the holding reply. A price the model writes itself still holds as `code:price`.
- Existing stops cover the code answer without new code: paused, opted out, reply cap (the code answer counts toward it), danger.

## Decisions Made

- Code checks and the length check run on the model's words only (with disclosure and sign-off), never on the sentence: the owner's sentence contains `$89` and would trip `code:price`. The combined length is measured with `SendCombinedReply::composedLength()` before sending.
- A refused send that is not a channel failure or an opt-out becomes an empty draft held as `send_refused`, matching how a refused model reply already behaves.
- Sentences picked alongside a hold (for example AC repair plus an unknown service) still go out with the partial holding line; the draft is empty and names only the held service.
