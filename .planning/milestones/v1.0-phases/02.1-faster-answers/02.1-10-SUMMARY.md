# Phase 02.1 Plan 10: Wrote-Again Flag and Forgotten-Offer Warning Summary

**The Needs you card now says "The customer wrote again since this draft" above Send (id comparison against the draft's `in_reply_to`), and the Business Folder page warns about an offer left running with no end date for more than 90 days (day 91 warns, business time zone).**

## Performance

- **Duration:** about 15 min
- **Completed:** 2026-10-14T21:01:45Z
- **Tasks:** 2
- **Files modified:** 8 (3 app/view, 2 test, WINDOWS.md ledger, sprint walk-through log)

## Accomplishments

- `ConversationThread::customerWroteAgain()` (computed): true when an inbound message of the conversation has an id above the largest id in the live draft's `meta['in_reply_to']`. It ignores the draft's own id and time, so a text that arrived while the run was in flight (lower id than the draft, not in its burst) still counts. A draft with no `in_reply_to`, or no live draft, gives false.
- The Needs you card shows the flag as a warning badge after the Customer wrote line and before the form, so it sits above Send.
- `BusinessFolder::staleOfferWarnings()` reads offers through `ActiveConfig` inside the `NoActiveVersion` guard and warns for each offer with no end date whose start date plus 90 days is before today's date in the business time zone. The page renders each in a red paragraph in an Offers section, only when there are any.
- The warning is display only: a test confirms `Sync Now` still activates the folder while it shows.
