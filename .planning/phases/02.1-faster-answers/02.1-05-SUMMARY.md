# Phase 02.1 Plan 05: The model hears about the waiting question Summary

**The front-desk model is told about a question already with the owner (cleaned customer words, never instructions, never mentioned in an unrelated answer) and answers in six new tolerant structured fields that only propose; code decides in later plans.**

## Performance

- **Duration:** 12 min

- **Tasks:** 2
- **Files modified:** 10

## Accomplishments

- Task 1 (tracer, end to end): Dana's price text is held as a draft; her next text reaches the model with an `## Already with the owner` section quoting the first text, after the customer card and before Right now. A replaced chain quotes every text oldest first. Quotes go through `OwnerAlertText::clean` and are cut to 300 characters.
- The rules now say: re-ask an intake question once with the options exactly as written (D-06), never mention the question that is with the owner, write one reply covering the whole thing when the text adds to it (D-23), and never write the price (D-04). "Never state or estimate a price" stays.
- Task 2: `AgentReply` and `FrontDeskAgent::schema()` carry `price_services`, `asks_discount`, `touches_waiting`, `waiting_note`, `easy_reply`, `easy_label`. Nine malformed shapes are covered; none throws.
- `RunFrontDesk` reads the conversation's live draft and passes it through `RunFrontDeskAgent` as `waitingDraft`. `promptText()` is unchanged.
