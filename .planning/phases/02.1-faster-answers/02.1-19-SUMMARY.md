# Phase 02.1 Plan 19: Jev Reads Vetoed Words, Close Needs Evidence Summary

**`DecideSendOrDraft::decide()` now asks Jev about every set of model words even when a veto already holds them, and `HeldReasons::priceAlone()` closes a draft as answered only on stored evidence: a customer reading that ran clean and, for model words, a words check that ran with price-only reasons.**

## Performance

- **Duration:** about 25 min
- **Completed:** 2026-10-16
- **Tasks:** 2 (a tracer and a TDD task)
- **Files modified:** 11 (2 in `app/`, 8 test files, 1 sprint walk-through)

## Accomplishments

- Jev reads vetoed words. A `label:price` draft whose words promise a time now carries `classifier:promise` in its stored words check, so a later price sentence can no longer close it. The veto still decides the reason; a Jev failure on a vetoed reply is recorded in `checks.classifier.error` and the reason stays the veto.
- A danger or a request for a person found in vetoed words still acts (safety line, hand-off), which is the D-45 "a words check can add a safety line or a handoff".
- `priceAlone()` no longer treats silence as agreement. A draft with no stored customer reading (one stored before gap plan 17), a reading that failed, did not run or has no answers, a reading that found a complaint, danger, request for a person or an unsure request, or model words with no words check that ran, is never closed as answered.
- The CR-02 probe (complaint, then a price sentence) is now a permanent test. It already passed once plan 02.1-18 held the complaint as `classifier:complaint`; it is kept as the guard on that behavior.
