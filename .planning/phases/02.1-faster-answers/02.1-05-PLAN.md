<objective>
Teach the front-desk model about this phase without giving it any new power: it is told about a question already with the owner (and never to mention it in an answer to something else), and it answers in six new structured fields that only propose (which services' prices were asked, a discount ask, whether the text touches the waiting question, check-in or added info, and a split-off easy part). Code decides everything in later plans.

Purpose: D-23 (the prompt fix), D-06 (re-ask once in the owner's words), and the structured fields D-04/D-05/D-13/D-18/D-19/D-29 need (Claude's Discretion names, frozen here).
Output: `FrontDeskPrompt` rules and the "Already with the owner" section, the waiting draft passed through `RunFrontDeskAgent`, `AgentReply` and `FrontDeskAgent::schema()` new fields, test defaults, the example agent file body.
</objective>
