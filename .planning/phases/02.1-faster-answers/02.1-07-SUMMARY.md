# Phase 02.1 Plan 07: Offers in the Owner's Folder Summary

**A new `offer` folder file type: one offer per file, indexed by slug, read through ActiveConfig, and checked at sync so the sentence's $ amounts and percentages must equal the file's amount_cents or percent**

## Performance

- **Duration:** 6 min
- **Started:** 2026-10-14T20:29:04Z
- **Completed:** 2026-10-14T20:35:00Z
- **Tasks:** 2
- **Files modified:** 13 (3 created, 10 modified)

## Accomplishments
- `offer` is a known file type end to end: `Loader::TYPED`, a `FolderSync::compile()` arm that indexes by slug (without it the default arm keeps one path for the whole type and a second offer silently replaces the first), `ActiveConfig::offers()` and `offer($slug)`, and shape rules in `Validator::rulesFor`.
- `Validator::offerErrors()` holds the sentence to its own field in both directions, refuses money words, bare numbers, fill-ins, promises and never_say phrases, refuses `end_date` before `start_date`, and refuses a repeated slug within the offer type. Every message is the exact plain-words line from the plan.
- The example folder has the fictional first-visit promotion and a README for the owner; it syncs with 14 typed files. `docs/SPEC.md` has the frozen `offer` row and folder tree entry.
