Laravel 13.35 facts (RESEARCH Pattern 3, read from framework source): `#[DebounceFor(int $debounceFor, ?int $maxWait = null)]` (`Illuminate\Queue\Attributes\DebounceFor`) plus a public `debounceId(): string` method; each new dispatch takes over the debounce and delays the job; an older superseded job is deleted when it runs; when the cache entry is gone the job runs anyway (fail open); a debounced job cannot also implement ShouldBeUnique. Tests run `QUEUE_CONNECTION=sync`, which runs jobs at once and ignores delays, so timing is proven with `Queue::fake()` and by calling `handle()` directly.
