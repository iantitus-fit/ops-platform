From the codebase (use as-is):
- `Loader::TYPED` (public const list) and `Loader::LATER_SPRINT` (private const list, currently holds `agent`).
- `Validator::rulesFor(IcmFile $file)` match arms return Laravel rule arrays; `Validator::fileErrors()` adds per-type extra checks via a `match ($file->type)`; cross-file checks follow `duplicateSlugErrors(Collection $files)` and are collected in `validate()`.
- `PlainWords::render($rule, $parameters, $field, $value)` turns a failed rule into the owner's sentence; dotted fields read as `fallback item 1: model`.
- `FolderSync::compile()` builds `['files' => [...], 'index' => ['service' => [], 'knowledge' => []]]`; its default arm stores one path per type (Pitfall 4).
- `ActiveConfig::typedFile(string $path): array` returns front matter plus `body`; `ActiveConfig::files()` lists every compiled path and type.
- `Laravel\Ai\Ai::textProvider(string $name)` throws `InvalidArgumentException` for an unknown provider and `LogicException` for one that cannot write text (verified in research); no key or network needed.

Created here:
- `App\Icm\ActiveConfig::agent(string $channel): ?array` (front matter plus `body`, or null when no agent serves that channel).
- `App\Ai\AgentFile` (readonly): `public string $name`, `public string $channel`, `public string $escalateTo`, `public string $body`; `providerChain(): list<array{provider: string, model: string}>`; `loads(): list<string>`; `static forChannel(ActiveConfig $activeConfig, string $channel): ?self`; `static fromArray(array $agent): self`.
- Compiled index key `index['agent'][<channel>] = <path>`.
</interfaces>

<assumption_delta_decision>
Signal: pluralization (`fallback`). The agent no longer names one provider; it names an ordered chain.
- Primary noun: the provider chain (`AgentFile::providerChain()`), primary entry first, then each fallback entry.
- Decision: promote. Every caller reads the chain; nothing reads `provider`/`model` as a single answer. The verdict (plan 02-07) records which entry answered.
- Invariant test suggested and adopted: AgentFileTest asserts the chain for the example file, and plan 02-07's fallback tests assert every entry is tried in order.
</assumption_delta_decision>
