# Services

One file for each service. Each file holds the service's name, how long it takes, whether it can be booked online, its price rule, the intake questions to ask before booking, and the price sentences the system may send on its own (how to write them is in `README.md`).

- `ac-repair.md`
- `furnace-repair.md`
- `furnace-tune-up.md`
- `system-replacement.md`

To add a service, copy a file here, change the name and slug, and sync.
