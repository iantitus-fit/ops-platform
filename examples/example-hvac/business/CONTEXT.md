# Business

Facts about the company itself. Read the file that matches the question.

- `profile.md`: name, phone, time zone and service area
- `hours.md`: weekly hours, closed dates and how much notice a booking needs
- `lead-sources.md`: where leads come from and what each one costs
- `faq.md`: plain answers to the questions customers ask most
- `services/`: one file for each service we sell
- `offers/`: one file for each offer the business is running
